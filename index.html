Thực hành C với Arduino IDE

Ví dụ trong bài học dùng main() và printf() để chạy bằng trình biên dịch C. Với Arduino IDE, hãy đưa hàm cần học vào tab bai_tap.c và gọi hàm từ sketch.

  1. Tạo sketch mới, thêm tab tên bai_tap.c.
  2. Nhập hàm C sau vào tab này.
int doi_phut_sang_giay(int phut)
{
    return phut * 60;
}

Trong tab .ino, dùng cầu nối dưới đây rồi nạp lên bo mạch.

extern "C" int doi_phut_sang_giay(int phut);

void setup() {
    Serial.begin(9600);
}

void loop() {
    Serial.println(doi_phut_sang_giay(2));
    delay(1000);
}

Mở Serial Monitor ở 9600 baud để thấy 120 mỗi giây. Các hàm C bạn học sẽ nằm trong tệp .c.
